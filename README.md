# Delta V - Delta Robot
This repository is where we develop a Delta Robot as a student project. It is currently in the early stages.
Detailed information on the design can be found in the [architectural report](https://github.com/CAt0mIcS/DeltaV/blob/main/docs/architecture/architecture.pdf).

## Stepper Motor Driver
For learning purposes, one of the three required stepper motor drivers will be designed by us. 
### Active development
* Four-layer PCB
* Feedback loop with inline current sensing and adaptive switching frequency
* FPGA controller with external logic interface
